# Legacy concept package - May 2026

These files are preserved for project history. They are **not current engineering specifications**.

The legacy diagrams and master plan contain earlier TALI-W definitions centered on bracing/support and include numerical dock values that have not been validated against the current flight-directed architecture. Do not use those values as design requirements.

The active project definition is in the repository root and `docs/` tree. Current numerical requirements remain `TBD` unless a verification method and evidence are recorded in the requirement matrix.
